# Design System - EduTrack AI

## Identidade Visual
O design deve transmitir uma estética moderna, dinâmica e com aspecto premium, seguindo as premissas estabelecidas na documentação.

### Cores
- **Cor Primária:** `#8c52ff` (Violeta vibrante).
- **Gradientes:** Utilizar gradientes com base na cor primária (tons violetas) para proporcionar profundidade e dar um aspecto mais premium aos elementos em destaque.

### Temas (Dark/Light Mode)
- A interface e os componentes devem oferecer suporte nativo tanto para o **Light Mode** quanto para o **Dark Mode**.
- O contraste de cores e legibilidade deve ser mantido independentemente do tema escolhido pelo usuário.

### Tipografia
- **Fontes Principais:** `Inter` e `Roboto`.
- Aplicar hierarquia semântica com diferentes pesos (Regular, Medium, Bold, etc.) para títulos, subtítulos e textos corridos.

### Formas e Bordas
- **Bordas Arredondadas (Border Radius):** Padrão de `16px` para cards, botões, modais e containers principais. Isso proporciona uma aparência mais suave e amigável, alinhada com as tendências modernas de UI.

## Recomendações de UI/UX
- **Animações (Micro-interações):** Adicionar efeitos suaves de hover e transições para uma sensação de que a interface está "viva" e responsiva.
- **Glassmorfismo:** Pode ser adotado pontualmente para complementar o visual moderno, especialmente no Dark mode.
